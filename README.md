# Hiking Trail Elevation & Grade Calculator

Add named waypoints with elevation (m) and distance from the previous point (km); the calculator computes total ascent, total descent, maximum grade percentage, and a difficulty rating using the Shenandoah formula. Estimated completion time uses Naismith's Rule adjusted by a pace slider, calorie burn is derived from MET values and body weight, and a visual elevation profile is rendered alongside a full exportable waypoint table.
